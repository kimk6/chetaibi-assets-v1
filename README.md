# Chetaïbi Municipality Assets Storage (v1)

This repository is dedicated to hosting the media assets and images for the official website of the **Chetaïbi Municipality**.

## 📋 Repository Purpose
- Hosting news images, event photos, and public announcements.
- Providing a fast and reliable CDN delivery via **jsDelivr**.
- Keeping the main website source code lightweight and performant.

## 🛠 Usage
Images are accessed via this structure:
https://cdn.jsdelivr.net/gh/kimk6/chetaibi-assets-v1@main/image-name.jpg
